# 🔐 OTP Verification – Ultra Premium UI

![OTP Verification Preview](preview(20).png)

A **high-end OTP verification screen** featuring glassmorphism, ambient glow, smooth input focus animations, multi-theme support, and a premium success confirmation overlay — built using **pure HTML, CSS & JavaScript**.

---

## ✨ Features
- 6-digit OTP input with auto-focus
- Floating glass UI with ambient glow
- Smooth input lift & glow on focus
- Gradient verify button with loader
- Premium success overlay with pulse animation
- Back button to retry verification
- 10 completely distinct UI themes
- Mobile-first 9:16 layout

---

## 🚀 How to Use
1. Download or clone this repo  
2. Open `index.html` in your browser  
3. Enter OTP digits  
4. Click **Verify** to see success animation  
5. Tap 🎨 to explore themes
