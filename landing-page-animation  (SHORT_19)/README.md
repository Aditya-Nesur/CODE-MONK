# 🔐 Premium Login → Animated Gallery Landing

![Premium Login Gallery Preview](preview(19).png)

A **premium animated login screen** that transitions into a **glassmorphic gallery landing page** with smooth motion, ambient glow, and multiple theme styles. Built using **pure HTML, CSS & JavaScript**.

---

## ✨ Features
- Animated login card with floating motion
- Loader → tick success animation
- Smooth login → landing page transition
- Glassmorphism UI with ambient glow
- Animated gallery cards (multiple entry styles)
- 10 premium color themes
- Back-to-login animated navigation
- Mobile-first 9:16 layout

---

## 🎨 Theme System
Tap the **Theme** button to cycle through **10 unique themes**:
- Cyber blue
- Neon pink
- Soft gold
- Clean light glass
- Dark minimal
- Green nature
- Red cinematic
- Silver frost
- Muted gray

Each theme updates:
- Background color
- Glow ambience
- Accent button color
- Gallery animation style

---

## 🎬 Animations Included
- Floating login card
- Ambient pulsing glow
- Button loader → success tick
- Page zoom & fade transitions
- Gallery stagger animations
- Smooth back navigation

## 🚀 How to Use
1. Download the folder  
2. Open `index.html` in browser  
3. Click **Theme** to change styles  
4. Login to see animated gallery landing ✨
