# 💬 Nexus Chat UI — Multi-Theme Experience

![Nexus Chat UI Preview](preview(28).png)

A **premium futuristic chat interface UI** with **glassmorphism**, **animated gradients**, **typing indicators**, and **10 dynamic themes**.  
Designed to simulate a modern AI chat experience using **pure HTML, CSS & JavaScript**.

Perfect for **UI inspiration, portfolios, frontend practice, and YouTube content**.

---

## ✨ Features

- 💎 Glassmorphism Chat UI
- 🎨 10 Dynamic Animated Themes
- 💬 Incoming & Outgoing Message Bubbles
- ⌨️ Typing Indicators (User & Bot)
- 🌌 Animated Background Blobs
- ⭐ Internal Star Effects
- 🧠 Smart Response Simulation
- 📱 Mobile-first 9:16 Layout
- ⚡ Pure HTML, CSS & Vanilla JavaScript
