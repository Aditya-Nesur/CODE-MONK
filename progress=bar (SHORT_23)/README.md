# 🚚 Live Order Tracking UI (Multi Theme)

![Live Order Tracking Preview](preview(23).png)

A **premium mobile-style Live Order Tracking interface** built using **pure HTML, CSS, and JavaScript**.  
Features **animated step progress**, **real-time status updates**, and **10 beautifully crafted themes** with ambient glow effects.

Perfect for **delivery apps, ecommerce UI demos, frontend inspiration, and YouTube Shorts**.

---

## ✨ Features

- 📦 **Live Order Status Tracker**
- 🔄 **Animated Step Progress Bar**
- 🎨 **10 Dynamic Color Themes**
- 🌈 **Ambient Glow Background**
- 🧩 **Glassmorphism Card UI**
- 📱 **9:16 Mobile App Layout**
- ⚡ **Smooth Micro-Animations**
- 🚀 **Pure HTML, CSS & JavaScript**
- ❌ No frameworks, no libraries
