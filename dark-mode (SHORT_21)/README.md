# 🎨 Advanced Settings – Global Themes UI

![Advanced Settings Preview](preview(21).png)

A **premium mobile-style Advanced Settings UI** built with **pure HTML, CSS, and JavaScript**.  
This project showcases **global theme switching, dark mode, ambient glow effects**, and a **modern app-like layout**.

Perfect for **UI inspiration, frontend practice, portfolios, and YouTube Shorts demos**.

---

## ✨ Features

- 🎨 **10 Global Premium Themes**
  - Ocean, Cyber, Sunset, Forest, Royal  
  - Mono, Candy, Teal, Gold, Blood
- 🌙 **Dark Mode Toggle**
- 💎 **Ambient Glow & Gradient Backgrounds**
- 📱 **Mobile App–Style 9:16 UI**
- ⚡ **Smooth Animations & Transitions**
- 🚀 **Pure HTML, CSS & JavaScript**
- ❌ No frameworks or libraries
