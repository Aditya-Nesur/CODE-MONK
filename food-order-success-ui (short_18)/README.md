# 🍔 Food Order Success UI

![Food Order Success Preview](preview(18).png)

A **premium food delivery order success screen** with smooth motion, animated background glow, theme switcher, rider animation, and celebration confetti. Built using **pure HTML, CSS & JavaScript**.

---

## ✨ Features
- Order confirmed success animation
- Glassmorphism UI with glow effects
- 10 beautiful gradient themes
- Animated SVG tick draw
- Delivery rider 🛵 motion
- Confetti celebration burst
- ETA display with smooth pop-in
- 9:16 mobile-first layout

---

## 🎨 Theme Switcher
Tap the **Theme** button to cycle through **10 premium color themes**:
- Warm food gradients
- Dark modern styles
- Neon & glass themes
- Minimal light mode

Each theme updates:
- Background gradient
- Glow colors
- Accent highlights

---

## ⚙️ Motion Details
- Floating animated glow background
- SVG tick draw animation
- Rider road animation
- Micro-interactions on text & cards
- Smooth fade, pop & slide effects

---

## 🧩 Use Cases
- Food delivery app UI
- Order success confirmation screen
- UI/UX animation inspiration
- YouTube Shorts / Reels demos
- Frontend portfolio showcase

---

## 🚀 How to Use
1. Download the folder  
2. Open `index.html` in browser  
3. Click **Theme** to change styles  
4. Enjoy the smooth order success animation 🎉
