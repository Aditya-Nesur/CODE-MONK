# 🎵 Premium Music Player – Theme Showcase

![Premium Music Player Preview](preview(25).png)

A **high-end animated music player UI** with **10 vibrant themes**, **ambient glow blobs**, and **smooth playback animations**.  
Designed for **UI inspiration, frontend practice, and YouTube Shorts demos**.

Built using **pure HTML, CSS, and JavaScript** — no libraries, no frameworks.

---

## ✨ Features

- 🎨 **10 Premium Gradient Themes**
- 🌈 **Animated Ambient Glow Blobs**
- 💿 **Rotating Album Art**
- 🎧 **Live Equalizer Animation**
- ⏯ **Play / Pause with Smooth Transitions**
- 📊 **Animated Progress Bar**
- 📱 **9:16 Mobile App UI**
- ⚡ **Pure HTML, CSS & JavaScript**
