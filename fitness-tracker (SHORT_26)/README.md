# 💪 Elite Fitness Tracker UI

![Elite Fitness Tracker Preview](preview(26).png)

A **next-gen animated fitness tracker UI** featuring **10 vibrant themes**, **activity-based animations**, and **real-time tracking visuals**.  
Perfect for **UI inspiration, frontend practice, and YouTube Shorts demos**.

Built with **pure HTML, CSS, and JavaScript** — no frameworks, no dependencies.

---

## ✨ Features

- 🌈 **10 Dynamic Animated Themes**
- 🧠 **Activity-Based Tracking**
  - Steps 🚶
  - Running 🏃
  - Calories 🔥
  - Heart Rate ❤️
  - Sleep 😴
- 💍 **Animated Circular Progress Ring**
- 📊 **Live Stats & Progress Bars**
- ✨ **Ambient Glow + Neon Grid Background**
- 🎬 **Smooth Page & Modal Transitions**
- 📱 **Mobile App (9:16) UI Layout**
- ⚡ **Pure HTML, CSS & Vanilla JS**
