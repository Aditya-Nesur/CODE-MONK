# 💸 UPI Payment Success UI

![UPI Payment Success Preview](preview(17).png)

A modern **UPI payment flow UI** with animated money transfer, theme switcher, and success confirmation. Designed for **fintech demos, payment apps, and UI inspiration** using pure HTML, CSS & JavaScript.

---

## ✨ Features
- PAY → Transfer → Success flow
- Animated ₹ money projectile between banks
- Glowing bank logos
- Success tick with pulse animation
- Confetti celebration on success
- Multiple color themes
- 9:16 mobile-friendly UI

---

## 🎨 Theme Switcher
Tap the 🎨 button to cycle through vibrant themes:
- Green (UPI style)
- Blue
- Red
- Purple
- Yellow

Each theme updates:
- Background gradient
- Button color
- Bank glow
- Success tick & text
