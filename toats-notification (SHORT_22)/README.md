# 🔔 Multi Theme Toast Notification UI

![Multi Theme Toast Preview](preview(22).png)

A **premium mobile-style Toast Notification system** built using **pure HTML, CSS, and JavaScript**.  
Includes **10 dynamic color themes**, animated toasts, wallet-style UI, and smooth micro-interactions.

Perfect for **modern apps, UI demos, frontend practice, and YouTube Shorts content**.

---

## ✨ Features

- 🔔 **Animated Toast Notifications**
  - Success
  - Error
  - Info
  - Warning
- 🎨 **10 Dynamic Color Themes**
- 💳 **Wallet-Style Demo UI**
- 🌈 **Ambient Glow & Gradient Backgrounds**
- 📱 **9:16 Mobile App Layout**
- ⚡ **Smooth Slide & Progress Animations**
- 🚀 **Pure HTML, CSS & JavaScript**
- ❌ No frameworks, no libraries
