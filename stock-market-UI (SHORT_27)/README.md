# 📈 NeoMarket — Live Analytical Finance UI

![NeoMarket Preview](preview(27).png)

A **premium glassmorphism-based finance dashboard UI** with **live stock simulations, animated charts, and multi-theme support**.  
Designed for **modern fintech apps, UI inspiration, and frontend showcases**.

Built using **pure HTML, CSS & Vanilla JavaScript** — no libraries, no frameworks.

---

## ✨ Features

- 🔴 **LIVE Market Indicator**
- 📊 **Real-time Stock Price Simulation**
- 📈 **Animated Line Charts**
- 💹 **Stocks & Mutual Funds Tabs**
- 🎨 **10 Premium Animated Themes**
- 🌌 **Ambient Neon Glow + Particles**
- 🪟 **Glassmorphism UI**
- 📱 **Mobile App (9:16) Layout**
- ⚡ **Pure HTML, CSS & JS**
